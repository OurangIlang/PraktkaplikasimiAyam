# Praktkview1 - Formulir Pemesanan Mi Ayam
Proyek praktikum apk android sederhana

## Widget Component
- **TextView**: Menampilkan label formulir dan judul antarmuka.
- **EditText**: Menerima input teks nama pemesan dengan validasi data kosong.
- **Spinner**: Menyediakan pilihan menu drop-down untuk varian mi ayam.
- **RadioGroup & RadioButton**: Opsi pemilihan porsi (Reguler / Jumbo) dengan mekanisme single-choice.
- **CheckBox**: Opsi pemilihan varian topping tambahan secara multi-choice.
- **Button**: Mengeksekusi pembacaan data input dan validasi formulir.
- **ListView**: Menampung serta menampilkan rekapitulasi daftar pesanan yang berhasil diproses.

## Specification
- **Code Languages**: Kotlin
- **IDE**: Android Studio
- **UI Compoment**: XML Layout (LinearLayout, Scrollable ListView)
- **Adapter**: ArrayAdapter (Android SDK)
